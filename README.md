# Inverse Kinematic with CCD Algorithm using pyray

![Python](https://img.shields.io/badge/Python-3.10+-blue.svg) ![Version](https://img.shields.io/badge/Version-v1.0-orange.svg) ![Course](https://img.shields.io/badge/Course-Computer%20Animation-blueviolet)

This program try to implementing ccd algorithm using pyray library to display the inverse kinematic.

---

## Features
Control the end effector using mouse input and Debug mode to view the changes.

---

## Dependencies

Programming language : Python version 3.10+
Library : Pyray

---

## How to run

1. Copy this repo and move to the directory

```
git clone git@github.com:Dhimasekaputraa/ccd-ik.git
cd ccd-ik
```

2. Create a virtual environtment
    For linux :
    
    ```
    python3 -m venv myvenv
    source myvenv/bin/activate
    pip install pyray
    ```

    For Windows :
    
    ```
    python -m venv myvenv
    myvenv\bin\activate
    pip install pyray

    ```
3. Run the program
  For linux :

    ```
    python3 main.py
    ```
    For Windows :

    ```
    python main.py
    ```
